# Laboratórios de Sistemas Digitais — ELT029

Repositório dos laboratórios semanais da disciplina **Laboratório de Sistemas Digitais (ELT029)**, desenvolvidos em dupla por Marco e Paulo Orbolato.

Os exercícios exploram projetos de circuitos digitais, como somadores, comparadores, flip-flops e máquinas de estados. O objetivo ao final do semestre é construir uma máquina de refrigerantes

## VHDL e FPGA

**VHDL** é uma linguagem de descrição de hardware usada para modelar e simular circuitos digitais. Diferentemente de uma linguagem de programação convencional, ela descreve componentes que podem operar em paralelo.

Uma **FPGA** é um circuito integrado reconfigurável: após escrever e sintetizar o VHDL, o projeto pode ser implementado na FPGA para que o hardware execute a lógica digital descrita.
